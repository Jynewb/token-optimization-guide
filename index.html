Why

为什么这个测试很重要？

成本差异巨大，用户痛点明确，市场缺乏系统性测试

💰

成本差异巨大

GPT-4 约 $10/百万 token，而国产模型免费或极便宜。选错模型可能浪费 10 倍成本。

🎯

痛点明确

用户不知道什么场景用什么模型。简单任务用贵模型 = 浪费；复杂任务用便宜模型 = 失败。

📊

缺乏系统测试

市面上没有针对 OpenClaw 场景的系统性 token 消耗测试，用户只能凭感觉配置。

⚡

实用价值高

测试结果直接指导用户配置，每月可节省大量成本，提升使用体验。

How

测试方法论

科学、严谨、可复现的测试流程

1

控制变量

相同任务、相同上下文、相同配置。每次只改变一个变量（模型），确保测试公平。

2

记录指标

输入 Token 数、输出 Token 数、总 Token 数、响应时间、任务完成质量（人工评分 1-5）。

3

重复测试

每个场景测试 3 次，取平均值。排除异常值，确保数据可靠。

4

新会话测试

每次测试使用新会话，避免上下文累积干扰。确保 Token 数据干净。

5

记录与对比

将所有数据记录到表格，横向对比不同模型在同一场景的表现。
